# Установка Homebrain на Mac

Распакуйте архив и один раз откройте Install Homebrain.command. Приложение установится в ~/Applications/Homebrain Launcher. Если macOS заблокирует первый запуск, откройте Системные настройки → Конфиденциальность и безопасность → Всё равно открыть. [Инструкция Apple](https://support.apple.com/en-us/102445).

При первой настройке укажите существующий SSH-псевдоним Homebrain или адрес пользователь@хост. Ключи и доверенный ключ сервера берутся из ваших настроек SSH. Папка дескриптора находится на Homebrain, по умолчанию ~/.local/share/homebrain-lab/handover.

Далее запускайте Homebrain.app или закрепите его в Dock. Он откроет общую страницу в выбранном браузере. Обычный режим запуска не требует разрешения на управление браузером. Повторный запуск может открыть ещё одну вкладку той же общей страницы.

Для изменения подключения или браузера откройте Homebrain Settings.command в папке установленного приложения. Настройки сохраняются автоматически. Редактировать файлы вручную не требуется.

Homebrain.command — вход из Terminal. Robot_Lab.command сохраняет прежнее меню отдельных программ. Приложение не запускает роботов или обучение при открытии.

Проверки камер, звука, геймпада и восстановления после сна выполняются отдельно от установки ярлыка.
