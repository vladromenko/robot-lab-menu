# Установка Homebrain на Mac

Распакуйте архив и один раз откройте Install Homebrain.command. Он установит приложение в ~/Applications/Homebrain Launcher с помощью встроенного компилятора macOS и откроет настройки подключения. Если macOS запросит подтверждение первого запуска скачанного установщика, используйте контекстное меню → Открыть.

Укажите уже используемый SSH-псевдоним Homebrain или адрес вида пользователь@хост. SSH возьмёт ключ и остальные параметры из ваших существующих настроек. Подтверждение ключа хоста и запрос парольной фразы выполняются через стандартный SSH.

Путь к папке дескриптора относится к Homebrain. По умолчанию это ~/.local/share/homebrain-lab/handover. Выберите установленный браузер. Если macOS запросит разрешение управлять этим браузером, разрешите его, чтобы Homebrain мог повторно открывать ту же вкладку.

После установки открывайте Homebrain.app из ~/Applications/Homebrain Launcher. Можно перетащить его в Dock. Приложение подключится и откроет общую лабораторию.

Для изменения адреса Wi-Fi, SSH или браузера откройте Connection settings. При занятом локальном порте выберите в настройках свободный порт. Сохранённые параметры находятся на Mac в ~/Library/Application Support/Homebrain/locator.json.

Резервный вход — Robot_Lab.command. Он открывает прежнее меню отдельных программ. Homebrain.command из Terminal открывает основное приложение.

Двойной щелчок Finder, разрешения браузера, микрофон, геймпад и восстановление после сна нужно проверить на Mac. Проверки на Homebrain описаны в MAC_LAUNCHER.md.
